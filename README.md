### 🧩 How they work (conceptual)

<details>
<summary><b>🌊 Milestone escrow flow (StellarFlow / Stellar Sentinel)</b></summary>

```mermaid
flowchart LR
    A[Funder] -->|locks XLM| B{{Soroban Escrow Contract}}
    B -->|milestone approved| C[Release payout]
    B -->|time-lock expires / dispute| D[Refund or arbitration]
    C --> E[(On-chain audit trail)]
    D --> E
```

</details>

<details>
<summary><b>🗳️ Private voting flow (ZKBallotChain)</b></summary>

```mermaid
flowchart LR
    V[Voter] -->|private inputs| C[Circom circuit]
    C -->|SnarkJS| P[Groth16 proof]
    P -->|submit| S{{Solidity verifier contract}}
    S -->|proof valid| T[Vote counted]
    S -->|proof invalid| R[Rejected]
```

</details>
