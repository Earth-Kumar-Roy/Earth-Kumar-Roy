### 🌐 About Me

I am a **Web3 Developer and Automation Engineer** building trustless, non-custodial decentralized infrastructure. My core focus centers on smart contract engineering across **Stellar (Soroban)**, **Ethereum (EVM)**, and **Solana**, alongside privacy-preserving cryptographic architectures using **Zero-Knowledge Proofs (ZK-SNARKs)**.

- 🛡️ **Treasury & Governance Defense:** Building autonomous protocol-level treasury management, time-locked escrow networks, and on-chain arbitration frameworks.
- 🔐 **Zero-Knowledge Architectures:** Architecting verifiably private systems using Circom, SnarkJS, Groth16, and Poseidon hash circuits.
- ⚡ **Rapid Tooling & Automation:** Developing lightweight web tools, serverless micro-apps, and automated pipelines across Google Apps Script, REST APIs, and modern frontend frameworks.
